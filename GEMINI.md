# 🌟 GEMINI.md — AI Development Standards for Stashly

Цей файл містить обов'язкові інструкції для AI-асистентів при роботі з цим репозиторієм.

## 📌 Основні правила та пріоритети

1. **Дотримання правил екосистеми (`/rules`):**
   - Усі правила в директорії [`rules/`](./rules) є обов'язковими до виконання.
   - Пріоритет: 1) Інструкції користувача ➔ 2) Платформні Web правила ➔ 3) Універсальні інженерні стандарти.

2. **Архітектура коду:**
   - **Feature-first:** Кожен доменний модуль живе в `src/features/<name>/` і експортує публічні сутності через `index.ts`.
   - **Типізація помилок:** Використовуйте класи з `src/lib/errors.ts` (`ValidationError`, `NotFoundError`, `AuthenticationError`, `InternalError`).
   - **Структуроване логування:** Використовуйте `src/lib/logger.ts` замість сирих `console.log`. Секрети та токени не повинні потрапляти в логи.
   - **Безпека:** Будь-який парсинг зовнішніх посилань повинен перевірятися на захист від SSRF (`validateSafeUrl` / `isPublicIp`).
   - **Константи маршрутів:** Використовуйте `Routes` із `src/lib/routes.ts`.

3. **Команди складання:**
   - `npm run build` — запуск продакшн-білду через Webpack.
   - `npm run dev` — запуск локального середовища розробки.
